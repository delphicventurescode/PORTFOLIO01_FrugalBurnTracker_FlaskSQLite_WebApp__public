# PORTFOLIO01 — Frugal Burn Tracker

**A Flask + SQLite web application for burn-rate and financial-runway analysis.**

The Frugal Burn Tracker is a small web application developed as **Portfolio Project #01**. It is designed to provide a simple way to analyze expenditure, burn rate, and financial runway.

The application was developed using **Google Antigravity**, an AI-powered coding agent, based on a defined set of application requirements.

---

## Technology

* **Python**
* **Flask**
* **SQLite**
