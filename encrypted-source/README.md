# Encrypted Source

This directory contains the source files for **PORTFOLIO01 — Frugal Burn Tracker** in an encrypted, password-protected archive.

The archive contains the project files generated during the development of the Flask/SQLite web application, including the application source code, templates, static assets, database schema, tests, and related project documentation.

## Contents

The project has been packaged as a **ZIP archive and encrypted/password-protected** before being uploaded to this repository.

### Project

**PORTFOLIO01 — Frugal Burn Tracker**

* **Framework:** Flask
* **Database:** SQLite
* **Language:** Python
* **Development tool:** Google Antigravity

## Access

The archive is intentionally password-protected.

**The password is not stored in this repository.**

If you have been provided with the password, use it to extract the archive locally.

For information about the project itself, please see the main repository README.
